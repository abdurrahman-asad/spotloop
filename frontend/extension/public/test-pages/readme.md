# Extension Test Pages

This directory contains HTML pages that are used for testing the extension in various scenarios. These pages simulate different web environments and interactions to ensure the extension functions correctly across various use cases.

## Purpose

Test pages help with:
- Manual testing of extension features
- Debugging issues with specific web page structures
- Ensuring compatibility with different DOM structures
- Testing extension behavior with dynamic content

## Accessing Test Pages

You can access these test pages locally when running the development server using:

```
http://localhost:5173/test-pages/<page-name>.html
```

For example:
- http://localhost:5173/test-pages/dynamic-iframe.html


## Usage

1. Start your development server
2. Open the test page URL in a browser with your extension installed
3. Interact with the page to test extension behavior in the specific scenario
